# Sunday Malls Design System

## Core principles

- Premium B2B vendor trust
- Mobile-first clarity
- clear operational hierarchy
- white-space confident and business-focused
- high contrast and legible labels
- action emphasis using orange and deep blue

## Typography

The project currently uses the Inter font loaded through Next.js. This keeps the app highly legible and consistent across dashboard cards, product detail screens, filters, and form fields.

## Layout system

- Header area with large brand treatment and small action cluster
- Card-based content sections with clear separation
- Dense but readable data blocks for metrics and KPIs
- Filter chips for rapid value screening
- Bottom navigation anchored inside the mobile frame for touch usability

## Behavioural guidance

- Use orange to draw attention to primary business actions
- Use blue to indicate trust, institution, and navigation
- Use green for successful or live states
- Use amber for warnings and pending actions
- Use red only for rejection or genuine risk indicators

## Reusable patterns

The current app uses a consistent pattern for:

- Page headers and intro blocks
- Metric cards for dashboards
- Product cards with price, stock, and status
- Order cards and settlement rows
- Enquiry cards and support interactions
- Device frame and mobile viewport presentation

## Notes

This is a design system for the frontend demo stage. It is intentionally built to support a clear mock-data vendor experience without backend or real service integrations.
